# Olist-Ecommerce-Analysis

🚀 Project Summary
This project analyzes the public Brazilian E-commerce dataset (Olist) to create an executive-level performance dashboard. The goal was to transform raw data into a visually compelling, actionable report covering sales, customer behavior, and logistics health.

## 📊 Tools Used
- **Excel**: Data cleaning & preprocessing
- **SQL**: Querying & analysis
- **Power BI**: Interactive dashboard creation

📂 Project Structure
- `data/` → Contains cleaned Excel datasets  
- `sql/` → Contains SQL queries used for analysis  
- `dashboards/` → Power BI dashboard file (`.pbix`)  
- `images/` → Screenshots of the dashboard
